# ADR-0165 — Excalidraw note drawings

Accepted. Supersedes the tldraw editor choice in ADR-0107.

Memnova uses the MIT-licensed Excalidraw React editor for editable diagrams in local notes. The editor loads on demand. Each drawing stores its scene and embedded image files in a fenced Markdown block. Study uses view mode. This release targets new drawings and provides no automatic tldraw migration.
