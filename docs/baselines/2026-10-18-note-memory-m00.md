`memnova-note-memory-performance.spec.ts`: **one test passes, 58.3s total, no retries**; three warm-up iterations and20 measured open/save iterations on an A4-sized synthetic note. Open uses Quick Open so virtualized list position does not contaminate the selection. Baseline p95: **176.83ms open**, **2072.35ms persisted save**. Save includes renderer flush, keyboard dispatch, actual file observation and the existing save/debounce behavior; it must not be presented as raw SQLite or disk latency. M24 must compare the same fixture, procedure and renderer mode, not development timing against production timing.

Existing fixture API dates render in a far-future year because of timestamp units; that browser-harness behavior is recorded, not claimed to reproduce native dates and not changed here.
